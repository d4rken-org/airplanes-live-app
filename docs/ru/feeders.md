# Приёмники
{: #feeders }

Приёмник, обычно Raspberry Pi с антенной, принимает сигналы воздушных судов и отправляет их в airplanes.live. Вкладка **Приёмник** следит за вашими приёмниками и предупреждает, когда какой-то из них отключается. Как настроить приёмник, описано в [руководстве по настройке airplanes.live](https://airplanes.live/get-started/).

Добавление приёмника здесь и его [привязка](/ru/getting-started#link-feeder) для Pro являются отдельными шагами. Можно сделать одно без другого.

## Как узнать ID фидера
{: #feeder-id }

У каждого приёмника есть ID фидера, UUID вида `3f2c8a1e-9b7d-4e2a-8c1f-5d6e7a8b9c0d`. На приёмнике, настроенном скриптом airplanes.live для передачи данных, его можно вывести командой:

```
cat /usr/local/share/airplanes/airplanes-uuid
```

В образе фидера airplanes.live это файл `/boot/airplanes-uuid`.

## Добавление приёмника
{: #add }

<a class="guide-shot" href="/assets/images/feeders/add-feeder.webp"><img src="/assets/images/feeders/add-feeder.webp" width="540" height="1200" loading="lazy" alt="Экран добавления приёмника с полями ID, метки, IP-адреса и местоположения"></a>

Нажмите кнопку **+** на вкладке «Приёмник». Заполнить **Новый приёмник** можно тремя способами:

- **Обнаружить Локальный Приёмник**: находит приёмники в той же сети, что и телефон, и заполняет поля. Если найдено несколько, выберите один.
- **Сканировать QR-код**: сканирует QR-код приёмника, созданный приложением на другом устройстве, см. [Поделиться приёмником](#share).
- Ввести **ID фидера** вручную.

Необязательные поля:

- **Метка**: название приёмника. Если его нет, приложение использует MLAT-имя приёмника из airplanes.live или последние пять символов его ID.
- **IP-адрес**: адрес, по которому для этого приёмника работает tar1090 или graphs1090, например `192.168.0.42`. Тогда приложение покажет кнопки для их открытия.
- **Позиция**: широта и долгота, например `50.8006, 6.0619`.

## Список приёмников
{: #list }

Заголовок показывает, все ли приёмники в сети. Для каждого приёмника показан его статус. Когда сервер приложения отслеживает ваши приёмники, для каждого приёмника также показаны частота сообщений Beast (сообщ./с), скорость передачи данных (Кбит/с) и статистика MLAT с долей выбросов и числом пиров. Без мониторинга сервером приёмник показывает «Мониторинг недоступен» и никаких частот. Список можно отсортировать по **Метке** или **Частоте сообщений**.

Когда сервер приложения отслеживает ваши приёмники, статус приходит с сервера, например «Ожидание первой проверки», «Не в сети с …» или «Возможен сбой airplanes.live». Проблемы, найденные сервером, показаны ниже, например «нет клиента MLAT». В бесплатной версии отслеживается меньше приёмников, чем с Pro. Приёмники сверх этого показывают «Не отслеживается, достигнут лимит приёмников» и кнопку **Повысить лимит**, чтобы [привязать свой приёмник](/ru/getting-started#link-feeder).

Нажмите на приёмник, чтобы увидеть больше:

- **Показать фид на карте**: открывает в браузере globe.airplanes.live с тем, что принимает этот приёмник.
- **Переименовать** и **Установить IP-адрес**.
- **TAR1090** и **GRAPHS1090**: открывают собственные веб-страницы приёмника. Они появляются, когда задан IP-адрес.
- **Мониторинг**: статус и проблемы этого приёмника по данным сервера, а также проверки, для которых ещё недостаточно данных. Без мониторинга сервером там написано «Мониторинг недоступен».
- **Статистика**: графики частоты сообщений, пиров MLAT и выбросов MLAT из почасовой истории сервера. Показывается, только когда сервер отслеживает ваши приёмники.
- **Создать QR-код**, см. ниже.
- **Уведомлять, когда offline**, см. ниже.
- **Удалить приёмник**.

## Уведомления об отключении
{: #offline }

**Уведомлять, когда offline** задаёт, сколько приёмник может быть не в сети, прежде чем вы получите уведомление: **Выкл.**, 6, 12, 24 или 48 часов. У новых приёмников стоит 48 часов. На Android 13 и новее при включении приложение запрашивает разрешение на уведомления.

Если сервер приложения это поддерживает, он отслеживает ваши приёмники, даже когда приложение закрыто. Приёмник считается отключённым, если у него не было соединения с airplanes.live в течение выбранного времени и это подтвердили как минимум две проверки. Сервер не считает приёмники отключёнными, пока у самого airplanes.live проблемы или много приёмников пропадает одновременно. Тогда вы получаете «Приёмник не в сети», а когда он вернётся, «Приёмник снова в сети».

Сервер также ищет проблемы и присылает «Проблемы приёмника», когда находит одну из них:

- нет клиента MLAT
- нет пиров MLAT
- ошибки синхронизации MLAT
- много выбросов MLAT
- принимает намного меньше сообщений, чем обычно
- постоянно переподключается
- ID фидера отправляется несколькими приёмниками

Отключить их можно в **Настройки** › **Приёмник** › **Оповещения о проблемах**.

Уведомления сервера приходят вместе с фоновой синхронизацией приложения, поэтому они могут задержаться на время, заданное режимом в **Настройки** › **Общие** › **Фоновая синхронизация**. См. [Как часто приложение синхронизируется](/ru/watchlist#interval).

Нажмите **Отложить** в уведомлении, чтобы этот приёмник не беспокоил вас, пока снова не появится в сети. Для проблем приёмника, который в сети, откладывание действует, пока они не исчезнут.

Без мониторинга сервером уведомлений об отключении нет, а ваши приёмники показывают «Мониторинг недоступен».

## Поделиться приёмником
{: #share }

**Создать QR-код** показывает QR-код с настройками приёмника. Отсканируйте его через **Сканировать QR-код** в приложении на другом устройстве, чтобы добавить туда тот же приёмник.
