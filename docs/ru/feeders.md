# Фидеры
{: #feeders }

Фидер представляет собой приёмник, обычно Raspberry Pi с антенной, который отправляет принятые сигналы воздушных судов в airplanes.live. Вкладка **Фидер** следит за вашими фидерами и предупреждает, когда какой-то из них отключается. Как настроить фидер, описано в [руководстве по настройке airplanes.live](https://airplanes.live/get-started/).

Добавление фидера здесь и его [привязка](/ru/getting-started#link-feeder) для Pro являются отдельными шагами. Можно сделать одно без другого.

## Как узнать ID фидера
{: #feeder-id }

У каждого фидера есть ID, UUID вида `3f2c8a1e-9b7d-4e2a-8c1f-5d6e7a8b9c0d`. На фидере, настроенном скриптом airplanes.live для передачи данных, его можно вывести командой:

```
cat /usr/local/share/airplanes/airplanes-uuid
```

В образе фидера airplanes.live это файл `/boot/airplanes-uuid`.

## Добавление фидера
{: #add }

Нажмите кнопку **+** на вкладке «Фидер». Заполнить **Новый фидер** можно тремя способами:

- **Обнаружить Локальный Фидер**: находит фидеры в той же сети, что и телефон, и заполняет поля. Если найдено несколько, выберите один.
- **Сканировать QR-код**: сканирует QR-код фидера, созданный приложением на другом устройстве, см. [Поделиться фидером](#share).
- Ввести **ID фидера** вручную.

Необязательные поля:

- **Метка**: название фидера. Если его нет, приложение использует MLAT-имя фидера из airplanes.live или последние пять символов его ID.
- **IP-адрес**: адрес, по которому для этого фидера работает tar1090 или graphs1090, например `192.168.0.42`. Тогда приложение покажет кнопки для их открытия.
- **Позиция**: широта и долгота, например `50.8006, 6.0619`.

## Список фидеров
{: #list }

Заголовок показывает, все ли фидеры в сети. Для каждого фидера показаны частота сообщений Beast (сообщ./с), скорость передачи данных (Кбит/с) и статистика MLAT с долей выбросов и числом пиров. Список можно отсортировать по **Метке** или **Частоте сообщений**.

Нажмите на фидер, чтобы увидеть больше:

- **Показать фид на карте**: открывает в браузере globe.airplanes.live с тем, что принимает этот фидер.
- **Переименовать** и **Установить IP-адрес**.
- **TAR1090** и **GRAPHS1090**: открывают собственные веб-страницы фидера. Они появляются, когда задан IP-адрес.
- **Статистика**: графики частоты сообщений и выбросов MLAT за 30 дней.
- **Создать QR-код**, см. ниже.
- **Уведомлять, когда offline**, см. ниже.
- **Удалить фидер**.

## Уведомления об отключении
{: #offline }

**Уведомлять, когда offline** включено для новых фидеров. Фидер считается отключённым, если airplanes.live не видит его 48 часов. Тогда приложение показывает уведомление «Обнаружены offline фидеры» с именем фидера. На Android 13 и новее при включении этой настройки приложение запрашивает разрешение на уведомления.

Нажмите **Отложить** в уведомлении, чтобы оно не появлялось, пока этот фидер снова не начнёт передавать данные. Уведомление исчезает само, как только фидер снова в сети.

Приложение проверяет фидеры в фоне. Частоту можно задать в **Настройки** › **Фидер** › **Интервал проверки**, от 15 минут до суток. По умолчанию проверка выполняется каждые 60 минут.

## Поделиться фидером
{: #share }

**Создать QR-код** показывает QR-код с настройками фидера. Отсканируйте его через **Сканировать QR-код** в приложении на другом устройстве, чтобы добавить туда тот же фидер.
