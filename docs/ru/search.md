# Поиск
{: #search }

Поиск находит воздушные суда, которые airplanes.live отслеживает прямо сейчас. Введите запрос в поле поиска и нажмите **Искать**.

## Что можно искать
{: #terms }

| Вы вводите | Что будет найдено |
|---|---|
| `DLH400` | позывной |
| `D-AIBL` | регистрация |
| `3C6589` | hex-код (24-битный адрес ICAO воздушного судна) |
| `A320` | тип воздушного судна |
| `7700` | код squawk (транспондера) |
| `FR5769` | воздушное судно, выполняющее пассажирский рейс с этим номером |
| `FR EIN FAO` | рейсы по авиакомпании, аэропорту вылета и аэропорту прилёта |

Слова сужают друг друга: `DLH A320` находит A320 авиакомпании Lufthansa. Альтернативы разделяйте запятыми: `7500, 7600, 7700` находит все три кода squawk.

Многие авиакомпании передают не тот код, что указан в номере рейса на билете. Если номер рейса ничего не находит, попробуйте маршрут из посадочного талона, например `FR EIN FAO`. Номера рейсов и маршруты работают только как отдельный запрос: в сочетании с другими словами или с **Рядом** они ничего не найдут.

## Фильтры
{: #filters }

- **Военные**: только военные воздушные суда.
- **Приватность**: только воздушные суда из программ конфиденциальности LADD и PIA.
- **Рядом**: воздушные суда вокруг выбранного места вместо поискового запроса. Сначала используется **Моё местоположение**. Нажмите **Изменить**, чтобы искать рядом с местом по названию, например «Берлин, Германия». Некоторые устройства не умеют искать места по названию; тогда работает только **Моё местоположение**.

**Военные** и **Приватность** сужают поиск. **Рядом** ищет вокруг выбранного места.

## Результаты
{: #results }

Если вы разрешите доступ к местоположению, результаты будут отсортированы по расстоянию от вас. Результаты с пометкой **Из кэша** получены при прошлых поисках и могут быть устаревшими. Нажмите на результат, чтобы посмотреть сведения. Нажмите и удерживайте результаты, чтобы выбрать несколько, а затем показать их вместе на карте.

## Ограничения
{: #limits }

В бесплатной версии поиск возвращает ограниченное число результатов («Показано X из Y совпадений»), а также действует дневной лимит поисков («Осталось поисков сегодня: X из Y»). Pro снимает ограничение на число результатов и значительно повышает лимит. См. [Бесплатная версия и Pro](/ru/getting-started#free-and-pro).
