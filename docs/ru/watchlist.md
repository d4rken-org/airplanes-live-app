# Список наблюдения и оповещения
{: #watchlist }

Наблюдение следит за чем-то вместо вас: за одним воздушным судном, рейсом, кодом squawk или областью. Наблюдения проверяет список наблюдения на сервере, а вкладка **Список наблюдения** показывает каждое наблюдение и то, что нашла последняя проверка. Включите для наблюдения уведомление, и приложение сообщит, когда цель появится.

## Добавление наблюдения
{: #add }

<a class="guide-shot" href="/assets/images/watchlist/add-watch.webp"><img src="/assets/images/watchlist/add-watch.webp" width="540" height="1200" loading="lazy" alt="Диалог добавления наблюдения с четырьмя типами"></a>

Нажмите кнопку **+** на вкладке «Список наблюдения» и выберите тип:

- **Самолёт (hex-код)**: одно воздушное судно по его hex-коду, 24-битному адресу ICAO, например `3C6589`. Также можно нажать **Добавить в список наблюдения** в сведениях о воздушном судне на карте.
- **Рейс (позывной)**: рейс по позывному, который он передаёт, например `DLH400`.
- **Код транспондера (SQUAWK)**: любое воздушное судно, передающее код squawk, например `7700` при аварийной ситуации.
- **Местоположение (радиус)**: воздушные суда рядом с местом, см. ниже.

К каждому наблюдению можно добавить заметку, чтобы помнить, зачем вы его добавили.

Наблюдения за кодами squawk и местоположениями входят в тариф Pro. См. [Бесплатная версия и Pro](/ru/getting-started#free-and-pro).

### Наблюдения за местоположением
{: #location }

Наблюдение за местоположением считает воздушные суда в пределах радиуса вокруг точки. Введите координаты или название места и нажмите **Определить** либо нажмите **Использовать моё местоположение**. Затем задайте метку и выберите радиус. Минимальный радиус 2 км, максимальный зависит от вашего тарифа.

Наблюдать за областью вокруг точки можно также, нажав на карту и удерживая палец. Если позже переместить область или изменить её размер, история наблюдения начнётся заново.

## Получение уведомлений
{: #notifications }

У нового наблюдения уведомления выключены. Откройте наблюдение и нажмите **Уведомление: выкл.**, чтобы переключить его на **Уведомление: вкл.**

Уведомление приходит, когда наблюдение переходит от «ничего» к «что-то»: замечено воздушное судно, позывной появился в воздухе, передаётся код squawk или в вашей области появились воздушные суда. Повторное уведомление приходит, только если в промежутке наблюдение ничего не видело. Если при самой первой проверке наблюдения что-то уже совпадает, это первое совпадение проходит без уведомления.

Когда приходит сразу много оповещений, приложение показывает несколько из них, а остальные объединяет в «Пропущенные уведомления списка наблюдения». Нажмите на уведомление, чтобы открыть его наблюдение.

Оповещения используют канал уведомлений «Уведомления списка наблюдения». Android должен разрешать приложению показывать уведомления. См. [Не приходят оповещения](/ru/faq#no-alerts).

## Как часто приложение синхронизируется
{: #interval }

Наблюдения проверяет сервер, а не приложение. Приложение получает результаты в фоне, когда есть подключение к сети, и тогда же приходят оповещения. Частоту можно задать в **Настройки** › **Список наблюдения** › **Интервал проверки**. По умолчанию синхронизация выполняется каждые 60 минут. В бесплатной версии минимальный интервал 60 минут, в Pro 15 минут.

Приложение также синхронизируется, когда вы открываете список наблюдения, а с последней синхронизации прошло больше 15 минут. Потяните список вниз, чтобы синхронизировать сразу.

Наблюдение, которое сервер ещё не принял, отмечено «Ожидание сервера». Если список наблюдения на сервере недоступен, в списке показано «Наблюдения сейчас не отслеживаются». Отслеживание возобновится, как только приложение свяжется с сервером.

## Сведения о наблюдении
{: #details }

Нажмите на наблюдение, чтобы увидеть:

- **Подходящие воздушные суда**: что нашла последняя проверка. Нажмите на воздушное судно, чтобы посмотреть сведения о нём.
- **Активность за 7 дней**: почасовая сетка того, когда наблюдение что-то видело.
- **Воздушные суда при каждой проверке, 30 дней**: для наблюдений за кодами squawk и местоположениями наибольшее число воздушных судов, которое сервер насчитал за каждый час.

В меню **Ещё** есть **Изменить заметку**, **Изменить область** для наблюдений за местоположением и **Удалить наблюдение**.

## Ограничения
{: #limits }

Бесплатная версия проверяет ограниченное число наблюдений, это показано как «Использовано X из Y бесплатных наблюдений». Наблюдения сверх лимита остаются в списке с пометкой «Не проверяется, превышен лимит». Проверяются те наблюдения, которые вы добавили первыми. Pro проверяет все.
