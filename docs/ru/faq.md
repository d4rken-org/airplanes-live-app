# Вопросы и решение проблем
{: #faq }

## Не приходят оповещения
{: #no-alerts }

Проверьте по порядку:

1. **Уведомления включены.** Новые наблюдения создаются с выключенными уведомлениями. Откройте наблюдение и переключите **Уведомление: выкл.** на **Уведомление: вкл.**
2. **Android разрешает приложению уведомления.** Откройте настройки Android › **Приложения** › **airplanes.live** › **Уведомления**, разрешите их и проверьте, что канал «Уведомления списка наблюдения» включён.
3. **Наблюдение проверяется.** Наблюдение с пометкой «Не проверяется, превышен лимит» в списке наблюдения вышло за лимит бесплатной версии. См. [Ограничения](/ru/watchlist#limits).
4. **Появилось что-то новое.** Оповещение приходит, когда наблюдение переходит от «ничего» к «что-то». Если воздушное судно уже совпадало при первой проверке наблюдения, это совпадение проходит без уведомления. Следующее оповещение придёт после того, как оно исчезнет и появится снова.
5. **Android разрешает приложению работать в фоне.** По умолчанию проверки выполняются каждые 60 минут. Режимы энергосбережения могут откладывать их ещё сильнее. Если оповещения приходят с опозданием, в настройках приложения в Android установите для использования батареи режим **Без ограничений**.

## Почему карта показывает только часть воздушных судов?
{: #map-capped }

При мелком масштабе карта показывает только часть воздушных судов в кадре и сообщает об этом вверху. Приблизьте карту, чтобы увидеть все. Если на карте написано «Дневной лимит карты исчерпан», лимит бесплатной версии на сегодня израсходован. См. [Бесплатная версия и Pro](/ru/getting-started#free-and-pro).

## Что означает «Дневной лимит поиска исчерпан»?
{: #allowance }

Бесплатная версия допускает определённое число поисков и запросов в день. Баннер сообщает, когда лимит обновится. Привязка фидера значительно повышает лимиты. См. [Бесплатная версия и Pro](/ru/getting-started#free-and-pro).

## Почему не видно воздушного судна?
{: #missing-aircraft }

airplanes.live видит только воздушные суда, которые находятся в зоне приёма какого-либо фидера и передают ADS-B или определяются через MLAT. Над океанами и в некоторых регионах покрытие слабое, а воздушные суда на земле или на малой высоте принимать сложнее. Вы можете помочь, [запустив свой фидер](https://airplanes.live/get-started/).

## Зачем приложению моё местоположение?
{: #location }

Только для функций, которым оно нужно: **Моё местоположение** на карте, сортировка результатов поиска по расстоянию, поиск **Рядом** и **Использовать моё местоположение** при добавлении наблюдения за местоположением используют ваше приблизительное местоположение. AR-виду нужны точное местоположение и камера. Всё остальное работает без доступа к местоположению.

## Как перенести наблюдения и фидеры на новый телефон?
{: #backup }

Откройте **Настройки** › **Резервное копирование и восстановление** и нажмите **Создать резервную копию**. Выберите, что включить: **Наблюдения** с историей проверок и **Фидеры** со статистикой. Приложение сохранит файл `.apl.zip`. На новом телефоне установите приложение и выберите **Восстановить резервную копию** с этим файлом.

Привязка фидера не входит в резервную копию. На новом телефоне снова [привяжите фидер](/ru/getting-started#link-feeder), чтобы получить Pro.

Восстановление гарантируется только для той же версии приложения, и приложение предупреждает, если версии различаются. Для резервной копии, созданной более новой версией, может потребоваться обновить приложение перед восстановлением.

## AR-метки указывают не в ту сторону
{: #ar-calibration }

Компас телефона нужно откалибровать. В AR-виде нажмите **Помощь**, затем несколько раз поводите телефоном восьмёркой. Держитесь подальше от металла и магнитов, например от машины или чехла с магнитом. Больше советов в [руководстве Google по калибровке](https://support.google.com/maps/answer/2839911).

## Фидер отключён, но уведомления не было
{: #feeder-offline }

Приложение предупреждает, только когда airplanes.live не видит фидер 48 часов, поэтому короткие перебои уведомления не вызывают. Также проверьте, что для этого фидера включено **Уведомлять, когда offline**, что уведомление не было отложено и что Android разрешает приложению уведомления. См. [Уведомления об отключении](/ru/feeders#offline).

## Собирает ли приложение данные обо мне?
{: #privacy }

Только то, что нужно для работы. Чтобы показать самолёты, приложение отправляет на сервер разработчика область карты, которую вы смотрите, ваши поиски и наблюдения, а также ваше местоположение, когда оно нужно функции. Это происходит под случайным ID установки, а не под учётной записью. Рекламы и аналитики нет, ничего не продаётся. Удалить свои данные можно в любой момент кнопкой **Удалить мои данные** в разделе **Настройки**. Подробности, в том числе сроки хранения данных, есть в [политике конфиденциальности](/privacy).
