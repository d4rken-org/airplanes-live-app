# Segnalare problemi
{: #reporting-problems }

## Fare una domanda
{: #questions }

Consulta prima le [FAQ](/it/faq). Per domande e chiacchiere:

- [Il Discord di darken](https://discord.gg/ENtVkMHqZg): la community dello sviluppatore dell’app.
- [Il Discord di airplanes.live](https://discord.gg/adsb): il Discord ufficiale di airplanes.live, per domande sulla rete, sulla copertura e sull’alimentazione.

Entrambi sono collegati anche in **Impostazioni** › **Supporto**.

## Segnalare un bug
{: #report }

Apri una segnalazione sul [tracker dei problemi](https://github.com/d4rken-org/airplanes-live-app/issues). Includi:

- la versione dell’app (indicata sotto **Registro delle modifiche** in **Impostazioni**) e da dove l’hai installata,
- il modello del telefono e la versione di Android,
- cosa hai fatto, cosa ti aspettavi e cosa è successo invece,
- uno screenshot o una registrazione dello schermo, se può essere utile.

Cerca prima tra le segnalazioni esistenti; qualcuno potrebbe averlo già segnalato.

## Registrare un log di debug
{: #debug-log }

Un log di debug registra tutto ciò che l’app sta facendo, e spesso mostra la causa di un problema.

1. Apri **Impostazioni** › **Supporto**, tocca **Registra log di debug** e conferma.
2. Fai ciò che causa il problema.
3. Torna in **Impostazioni** › **Supporto**, tocca **Ferma registrazione** e condividi il file.

Il log può contenere informazioni sensibili, come la tua posizione o l’ID del tuo alimentatore. Condividilo solo con persone di cui ti fidi. Se preferisci non allegarlo a una segnalazione pubblica, chiedi sul Discord di darken dove inviarlo.
