# Suche
{: #search }

Die Suche findet Flugzeuge, die airplanes.live gerade verfolgt. Tippe etwas in das Suchfeld und tippe auf **Suchen**.

## Wonach du suchen kannst
{: #terms }

| Du tippst | Es findet |
|---|---|
| `DLH400` | ein Rufzeichen |
| `D-AIBL` | eine Registrierung |
| `3C6589` | einen Hexcode (die 24-Bit-ICAO-Adresse des Flugzeugs) |
| `A320` | einen Flugzeugtyp |
| `7700` | einen Squawk-Code (Transpondercode) |
| `FR5769` | das Flugzeug, das eine Passagier-Flugnummer fliegt |
| `FR EIN FAO` | Flüge nach Airline, Abflug- und Ankunftsflughafen |

Mehrere Wörter grenzen sich gegenseitig ein: `DLH A320` findet A320 der Lufthansa. Trenne Alternativen mit Kommas: `7500, 7600, 7700` findet alle drei Squawk-Codes.

Viele Airlines senden einen anderen Code als die Flugnummer auf deinem Ticket. Wenn eine Flugnummer nichts findet, probiere die Route von deiner Bordkarte, etwa `FR EIN FAO`. Flugnummern und Routen funktionieren nur als eigener Suchbegriff; kombinierst du sie mit anderen Wörtern oder **In der Nähe**, finden sie nichts.

## Filter
{: #filters }

- **Militär**: nur Militärflugzeuge.
- **Privatsphäre**: nur Flugzeuge in den Datenschutzprogrammen LADD und PIA.
- **In der Nähe**: Flugzeuge rund um einen Ort statt eines Suchbegriffs. Ausgangspunkt ist **Mein Standort**. Tippe auf **Ändern**, um in der Nähe eines Ortsnamens wie „Berlin, Deutschland“ zu suchen. Manche Geräte können keine Ortsnamen nachschlagen; dann funktioniert nur **Mein Standort**.

**Militär** und **Privatsphäre** grenzen die Suche ein. **In der Nähe** schaut sich rund um einen Ort um.

## Ergebnisse
{: #results }

Wenn du den Standortzugriff erlaubst, werden die Ergebnisse nach ihrer Entfernung von dir sortiert. Ergebnisse mit der Markierung **Zwischengespeichert** stammen aus früheren Suchen und sind womöglich veraltet. Tippe auf ein Ergebnis, um seine Details zu sehen. Drücke lange auf Ergebnisse, um mehrere auszuwählen, und zeige sie dann gemeinsam auf der Karte.

## Limits
{: #limits }

In der kostenlosen Stufe liefert eine Suche nur eine begrenzte Anzahl an Ergebnissen („X von Y Treffern werden angezeigt“), und es gibt ein tägliches Suchkontingent („Heute noch X von Y Suchen übrig“). Pro hebt die Begrenzung auf und erhöht das Kontingent deutlich. Siehe [Kostenlos und Pro](/de/getting-started#free-and-pro).
