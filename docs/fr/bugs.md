# Signaler un problème
{: #reporting-problems }

## Poser une question
{: #questions }

Consultez d’abord la [FAQ](/fr/faq). Pour les questions et la discussion :

- [Discord de darken](https://discord.gg/ENtVkMHqZg) : la communauté du développeur de l’application.
- [Discord d’airplanes.live](https://discord.gg/adsb) : le Discord officiel d’airplanes.live, pour les questions sur le réseau, la couverture et l’alimentation.

Les deux sont aussi accessibles depuis **Paramètres** › **Support**.

## Signaler un bug
{: #report }

Ouvrez un ticket sur le [suivi des problèmes](https://github.com/d4rken-org/airplanes-live-app/issues). Indiquez :

- la version de l’application (affichée sous **Journal des modifications** dans **Paramètres**) et l’endroit où vous l’avez installée,
- le modèle de votre téléphone et la version d’Android,
- ce que vous avez fait, ce à quoi vous vous attendiez et ce qui s’est passé à la place,
- une capture d’écran ou un enregistrement d’écran si cela aide.

Cherchez d’abord parmi les tickets existants ; quelqu’un l’a peut-être déjà signalé.

## Enregistrer un journal de débogage
{: #debug-log }

Un journal de débogage enregistre tout ce que fait l’application, ce qui révèle souvent la cause d’un problème.

1. Ouvrez **Paramètres** › **Support**, appuyez sur **Enregistrer le journal de débogage** et confirmez.
2. Reproduisez ce qui cause le problème.
3. Revenez dans **Paramètres** › **Support**, appuyez sur **Arrêter l'enregistrement** et partagez le fichier.

Le journal peut contenir des informations sensibles, comme votre position ou l’ID de votre alimentateur. Ne le partagez qu’avec des personnes de confiance. Si vous préférez ne pas le joindre à un ticket public, demandez sur le Discord de darken où l’envoyer.
